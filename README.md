# Ravenswood Ledger

Ravenswood Ledger is a private-by-default companion for running and playing Blood on the Clocktower. It is a static site: no account, backend, analytics, or build step is required.

**Live site:** https://tabaxi3000.github.io/clocktower-companion/

## Included tools

- legal setup and recommended cast generation for three base scripts, A Grimm Chorus, and three Teensyville scripts;
- distinct visual theme for every script;
- all eighteen current Travellers as optional extra players;
- Big Wig, Gardener, God of Ug, and Hindu Loric controls;
- hidden setup validation, Demon bluffs, private handoff, and optional SMS drafts;
- Grimoire, night queue, event timeline, nominations, weighted votes, claims, information, and possible worlds;
- player-safe workspace, role strategy, searchable rules, complete character reference, and public night order;
- private, redacted, and Markdown exports.

## Privacy

Games are stored only in the current browser's local storage unless the user exports them. The repository contains no saved games or phone numbers. A full private export can contain phone numbers, roles, hidden setup, and Storyteller notes; handle it accordingly.

## Local use

Open `index.html` directly or serve this folder with any static web server. There are no dependencies to install.
